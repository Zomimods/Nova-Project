# ملخص إصلاح المشروع

## ما تم إصلاحه

- إضافة اعتماد Media3 DASH الناقص من version catalog.
- جعل `extract_v20.py` يعمل من أي مجلد، وإضافة `--check` للتحقق من تطابق واجهة V20 المضمّنة مع المصدر.
- إصلاح تسلسل تهيئة V20 بحيث لا يمنع تعطل ميزة اختيارية ظهور بقية الواجهة، ثم إعادة إنشاء ملف HTML المضمّن من المصدر.
- إضافة فحص تطابق المصدر والملف المضمّن إلى CI وإلى مسار إصدار APK.
- تقييد أذونات WebView بالميكروفون فقط وتعطيل الوصول غير الضروري إلى الملفات.
- تصحيح وثائق Firebase: واجهة V20 تستخدم إعداد Firebase Web وRealtime Database المضمّنين؛ إعداد Firestore الأصلي لا يؤمّن قاعدة Realtime Database.

## التحقق

- نجح `python3 extract_v20.py --check` من جذر مساحة العمل.
- نجح تحليل ملفات Android XML، وتأكد وجود اعتماد DASH الذي يستخدمه Gradle.
- روابط HTTP التسعة عشر في كتالوج القنوات موزعة على 16 مضيفًا، وجميعها ضمن قائمة السماح الحالية.

## ما لم يُختبر

لم يكتمل بناء APK أو اختبارات Gradle لأن Android SDK غير مضبوط في بيئة العمل. كما أن قواعد Realtime Database الفعلية غير موجودة في الأرشيف؛ راجعها واختبرها قبل النشر، ولا تعتمد على `firestore.rules` لتأمينها.
